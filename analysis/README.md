# 成对连续块自举：2 成分 vs 3 成分的留样相对残差增量

回答的问题：FastICA 保留成分数从 3 降到 2 后，**留样相对残差会增加多少**（百分点）。
算法口径完全复用 `backend/src/domain`（同一 FastICA 参数、秩阈值与相对残差公式），
本目录只做重抽样与成对比较，不改动领域实现。

## 自举设计（与需求逐条对应）

1. **固定种子、连续块有放回抽样。** 主种子 `--seed`（默认 20261126）按轮号派生
   每轮独立 RNG（`SeedSequence([seed, round])`），轮号固定则抽块序列固定。
2. **两段各自在段内抽块，不跨段。** 校准段（160 点）与留样段（80 点）分别抽
   长度 `--block-size`（默认 10 点 = 2.5 ms）的连续块，块数向上取整后截断回原长度。
3. **两种成分数共用同一轮抽样。** 每轮一个重抽样矩阵，分别拟合 2 成分和 3 成分，
   增量为成对差值 `Δ = 留样相对残差(2) − 留样相对残差(3)`。
4. **只用校准块拟合。** 留样块只用于评分；相对残差为
   `100 × RMS(留样残差) / RMS(重抽校准信号去中心)`，与 `reporting.py` 整体口径一致。
5. **一侧秩不足或未收敛，整轮记失败、不补抽。** 失败轮照常占用一个轮号，
   总轮数不增加；只算出一侧残差（另一侧失败）同样没有增量，按失败处理。
   失败原因分三类：`rank_deficient`、`not_converged`、`numeric_error`。
6. **中断续跑只补缺轮。** 状态按轮号存盘，重跑时仅调度缺失轮号；
   已定论轮（含失败轮）不重算。轮数是运行目标、不属于自举口径，续跑时可以扩大。
7. **并发/重试不重复计轮。** 落盘走文件锁（`flock`）+ 按轮号 `setdefault` 合并 +
   原子替换，多进程并发或失败重试都不会产生重复轮。
8. **全部跑完才报区间。** 95% 区间取成对增量的 2.5% 与 97.5% 分位（百分位法）；
   有效轮不足两轮时 `reported=false` 且不给出任何区间数值。
9. **续跑结果与一次跑完一致。** 由每轮确定性 RNG 与轮号去重共同保证，
   `tests/test_bootstrap.py` 有逐轮断言。

## 用法

```sh
/workspace/.venv/bin/python -I analysis/bootstrap_ica.py \
  --csv analysis/data/LHY-G07-064_台架四麦.csv \
  --state-dir analysis/state/main-b10 \
  --rounds 1000 --block-size 10 --seed 20261126 --workers 4
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--rounds` | 1000 | 自举总轮数（失败轮不补，有效轮可能更少） |
| `--block-size` | 10 | 连续块采样点数，校准/留样两段共用 |
| `--seed` | 20261126 | 固定主种子 |
| `--max-iter` | 600 | FastICA 迭代上限，与业务默认一致 |
| `--workers` | 1 | 并发工作进程数 |
| `--flush-every` | 20 | 每多少轮落盘一次 |
| `--reset` | 关 | 清除同目录旧状态后重跑 |

更换 `--block-size/--seed/--max-iter/--csv` 而沿用旧 `--state-dir` 会被配置守卫拒绝，
需显式 `--reset` 或换目录，避免把不同口径的轮次混在一起。

## 产物

- `bootstrap_state.json`：配置 + 每轮记录（两侧残差、增量、失败原因、迭代次数），续跑依据。
- `bootstrap_report.json`：轮次计数、失败原因分布、95% 分位区间（未跑完/有效轮不足时不报）、
  完成后的全量成对增量数组。

## 测试

```sh
/workspace/.venv/bin/python -I analysis/tests/test_bootstrap.py
```

覆盖：确定性与成对增量、续跑逐轮等于一次跑完、秩不足/未收敛整轮失败且不补抽、
有效轮不足两轮不报区间、未跑完不报区间、三进程并发不重复计轮且与串行一致、
重抽不跨段边界。
